1. INTRODUCTION                                            *mdpv* *mdpv-intro*

Previews the current buffer in a browser tab and updates it as you edit.
GitHub and Obsidian syntax render together (|mdpv-syntax|); the look is
GitHub's or Obsidian's (|mdpv-styles|). The server is pure Lua on |vim.uv|:
nothing to install or build.

Requires Neovim 0.12+ and a browser.

==============================================================================
2. COMMANDS                                                         *:Preview*

  :Preview            open the current buffer's preview in the browser; if a
                      tab already shows it, report that instead
  :Preview!           same, for a buffer outside `filetypes`
  :Preview close      close the current buffer's preview
  :Preview toggle     open or close it; `!` forces like :Preview!
  :Preview list       list previews with their URLs and attached tabs
  :Preview stop       close all previews and stop the server

==============================================================================
3. CONFIGURATION                                                 *mdpv-config*

`setup()` is optional. Defaults: >lua

  require('mdpv').setup({
    host = '127.0.0.1',
    port = 0,                   -- 0 = any free port
    theme = 'auto',             -- 'auto' | 'light' | 'dark'
    style = 'github',           -- 'github' | 'obsidian'
    debounce = 150,             -- ms before pushing an edit
    filetypes = { 'markdown' }, -- previewable without :Preview!
    follow_buffer = false,      -- see |mdpv-follow|
    auto_close = true,          -- close a preview when its buffer unloads
    auto_stop = true,           -- stop the server after the last preview
    open_browser = true,
    math = true,
    mermaid = true,
    emoji = true,
    reload_images = true,       -- reload images that change on disk
    scroll_sync = true,         -- see |mdpv-sync|
  })
<
`theme`, `style`   Initial values. The page's pickers override them and save
                   the choice (|mdpv-menu|).
`filetypes`        Compound filetypes match on any part.
`open_browser`     true: |vim.ui.open()|. false: only print the URL. A
                   command list: `{ 'firefox', '--new-window' }`. A
                   `function(url)`.
`math`             true, false, or KaTeX options:
                   `{ macros = { ['\\RR'] = '\\mathbb{R}' } }`.
`scroll_sync`      true: the page follows the cursor. 'both': scrolling the
                   page also moves the cursor. false: neither.

Unknown keys warn; invalid values error. Calling `setup()` again updates open
previews; pages reload when rendering changes. `host` and `port` can't change
while previews are open.

4. LUA API                                                          *mdpv-api*

{bufnr} defaults to the current buffer.

require('mdpv').open({bufnr}, {opts})                            *mdpv.open()*
    Open a preview and return its URL. `opts.force` skips the `filetypes`
    check.

require('mdpv').close({bufnr})                                  *mdpv.close()*
    Close the buffer's preview.

require('mdpv').toggle({bufnr})                                *mdpv.toggle()*
    Close the buffer's preview if it has one, else open one.

require('mdpv').url({bufnr})                                      *mdpv.url()*
    URL of the buffer's preview, or nil.

require('mdpv').list()                                           *mdpv.list()*
    Open previews: `{ { bufnr, title, url, follow, tabs }, ... }`.

require('mdpv').stop()                                           *mdpv.stop()*
    Close all previews and stop the server.

5. SYNTAX                                        *mdpv-syntax* *mdpv-callouts*

One syntax, no modes: GitHub's, plus Obsidian's where GitHub would show
plain text.

GitHub     tables, task lists, alerts, footnotes, math, Mermaid, `:emoji:`,
           frontmatter as a table, sanitized raw HTML; code highlighted
           with GitHub's grammars and colors (starry-night, about 80
           languages; others stay plain)
Obsidian   callouts: GitHub's alerts plus Obsidian's types, custom titles,
             folding (`[!faq]-`, `[!tip]+`), nesting
           `[[page]]`, `[[page|alias]]`, `[[page#heading]]`, `[[page#^id]]`
           `![[img.png]]`, `![[img.png|300]]`, `![alt|300x200](img.png)`;
             other embeds become links
           `==highlight==`, `%%comment%%` (inline or block), `#tag`,
           `^[inline footnote]`
           `^id` ending a paragraph or list item, or alone after a block:
             names it for `[[#^id]]`

6. SYNC AND JUMPING                                    *mdpv-sync* *mdpv-jump*

The page scrolls to the cursor line and marks the block under it. On a
heading line, the URL hash follows (`#heading`).

Two switches in the menu (|mdpv-menu|):

  Follow cursor          the page follows the cursor (`f`); on by default
  Move cursor on scroll  scrolling the page moves the cursor; on by default
                         only with `scroll_sync = 'both'`

With `scroll_sync = false` both are off and hidden.

Double-click the page to jump: the cursor lands on the line clicked, folds
open, view centered. Works regardless of `scroll_sync`.

==============================================================================
7. FOLLOWING BUFFERS                                             *mdpv-follow*

With `follow_buffer = true` there is one shared preview. Entering a normal
file buffer whose filetype is in `filetypes` switches it to that buffer;
help, terminals, scratch buffers, and floating windows don't. The preview
survives its buffer being unloaded and stays open until `:Preview close`.
Turning `follow_buffer` off keeps it open on the buffer it shows.

8. THE PAGE                                                        *mdpv-page*

KEYS                                                               *mdpv-keys*

  j  k      scroll                 o   outline
  d  u      half page              w   full width
  gg  G     top, bottom            t   cycle theme
  ]]  [[    next, prev heading     s   cycle style
  m         menu                   f   follow cursor
  ?         shortcuts

MENU                                                               *mdpv-menu*

The floating button opens the menu: sync switches, outline, full width,
theme, style, shortcuts. Its dot shows the connection: live, reconnecting,
closed (by Neovim), or disconnected (Neovim is gone). Drag the button or the
outline to any corner.

Choices are saved in `stdpath("state")/mdpv-prefs.json` and apply to every
open tab, across sessions.

STYLES                                                           *mdpv-styles*

  github     github-markdown-css (default)
  obsidian   Obsidian's default theme: colors, headings, lists, callouts,
             checkboxes, code; frontmatter as Properties

Each works in every theme: light, dark, or auto (follows the system). Only
CSS changes; the markup is the same.

OUTLINE                                                         *mdpv-outline*

A rail of dashes, one per heading, with the current section marked. Hover
to expand it into the heading list; click a heading to go there.

RENDERING                                                   *mdpv-rendering*

- Task checkboxes toggle the buffer's line, unless it isn't modifiable.
- Code blocks get a copy button. The highlighter warms up with the page;
  each language, KaTeX, and Mermaid load on first use.
- Relative links and images resolve against the file's directory and can't
  reach above it. Linked `.md` files open as static pages; add `?raw` for
  the source.

SECURITY                                                       *mdpv-security*

- Localhost only; every preview URL carries an unguessable token.
- Raw HTML is sanitized, and pages use a strict CSP.
- Paths escaping the file's directory, including symlinks, are rejected.
- HTML files download instead of rendering.

==============================================================================
9. HEALTH                                                        *mdpv-health*

`:checkhealth mdpv` checks the Neovim version, assets, browser opener,
preferences path, and server state.
